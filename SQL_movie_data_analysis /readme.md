# 🎬 Project 4: Bee Movies Data Analysis (SQL + Insights Report)


## 📘 Overview

Bee Movies is an Indian film production company which has produced many super-hit movies. They have usually released movies for the Indian audience but for their next project, they are planning to release a movie for the global audience in 2022.

The production company wants to plan their every move analytically based on data and have approached you for help with this new project. You have been provided with the data of the movies that have been released in the past three years. You have to analyse the data set and draw meaningful insights that can help them start their new project.



## 🧩 Files in This Project

| File | Description |
|------|--------------|
| **import_data.sql** | SQL script to create tables and import raw data into the database |
| **requirement.sql** | Contains the 29 analytical questions (Q1–Q29) provided in the assignment |
| **answers.sql** | All final SQL queries answering each question |
| **ERD.xlsx** | Entity Relationship Diagram showing table relationships |
| **Executive Summary.pdf** | Final report summarizing key findings and recommendations |

---

## ⚙️ How to Run the Project

1. **Setup Database**
   - Create a new PostgreSQL database (e.g., `bee_movies`).
   - Run `import_data.sql` to create and populate all tables.

2. **Explore Requirements**
   - Open `requirement.sql` to view all business questions (Q1–Q29).

3. **Run Analysis**
   - Execute the queries from `answers.sql` in order.
   - Each query answers a specific question from the requirement file.

4. **Review Insights**
   - Open `Executive Summary.pdf` for a professional overview of key insights and strategic recommendations for Bee Movies.

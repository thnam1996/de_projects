# ETL Pipeline: VM/MongoDB → Google Cloud Storage → BigQuery

### Automated Multi-Table Data Pipeline using Cloud Functions

## 1. Project Overview

This project implements a fully automated ETL pipeline for three
independent datasets, each extracted from a VM/MongoDB environment and
ingested into BigQuery Raw Layer.

The pipeline follows a modular, scalable, and production-ready
architecture.

## 2. Architecture Diagram

MongoDB / VM → Export Scripts → GCS → Cloud Functions → BigQuery Raw

## 3. Learning Objectives

-   ETL processes
-   Cloud Storage
-   Cloud Functions triggers
-   BigQuery integration
-   Data Profiling & Monitoring
